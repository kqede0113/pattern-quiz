# パターン認識 暗記カード

パターン認識の期末テスト対策用の暗記カード練習アプリ（ビルド不要の静的サイト）。

**公開ページ:** https://kqede0113.github.io/pattern-quiz/

## できること
- カードをタップ（PCはスペース）でめくって答えを確認
- 「覚えた / まだ」を記録し、「苦手だけ」「まだだけ」で復習
- 「重要だけ」「演習③だけ」で絞り込み。各カードに第14回の項目番号と演習③の印を表示
- 節（章）ごとに絞り込み、シャッフル
- 予想記述問題は、自分で書いてから「骨子を見る」で模範解答の骨子と比較（下書きも自動保存）
- 進み具合はブラウザ（localStorage）に保存。問題文が同じなら source.md を差し替えても記録は引き継がれる

キー操作: スペース/Enter=めくる、→/←=次/前、1・O=覚えた、2・X=まだ、Esc=ホーム

## ファイル
| ファイル | 役割 |
|---|---|
| `source.md` | 問題の元データ（これを差し替える） |
| `build.py` | source.md → data.js を生成（Python 3 標準ライブラリのみ） |
| `data.js` | 生成された問題データ（直接編集しない） |
| `index.html` / `style.css` / `app.js` | アプリ本体 |

## source.md を差し替えたとき
```bash
python3 build.py          # data.js を作り直す（節ごとの問題数が表示される）
git add -A && git commit -m "問題データ更新" && git push
```
push すると GitHub Pages（main ブランチ直下）が自動で更新される（1〜2分）。**data.js を作り直してから push すること。**

### source.md の書式
```markdown
# タイトル
## 1. 節の名前（スライド 13–24）
**Q1.** 問題文
**A.** 答え（次の問題・見出しまで複数段落や箇条書きも可）

## 19. 予想記述問題
節の説明（任意）
**問題1.** 記述問題の問題文
**骨子.** 模範解答の骨子
```
`**問題N.**` / `**骨子.**` の問題は記述形式（入力欄つき）で出題される。

## ローカルで確認
`index.html` をブラウザで直接開くか、`python3 -m http.server` で配信して開く。
